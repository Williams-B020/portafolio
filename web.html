Páginas Web

Diseñado para Conectar Estilo y Experiencia

Este proyecto es una tienda en línea de muebles diseñada para ofrecer una experiencia de compra intuitiva y visualmente atractiva. Se enfocó en resaltar la estética de los productos mediante un diseño limpio y moderno, con navegación sencilla y elementos interactivos que facilitan la exploración del catálogo. La página busca combinar funcionalidad y estilo, mostrando cómo el diseño web puede potenciar la presentación de productos de manera efectiva.

Año

Esta página web de recetas fue diseñada como un blog moderno y fácil de navegar, donde cada platillo se presenta con imágenes atractivas, instrucciones claras y una estructura organizada. El objetivo del proyecto fue crear una experiencia visual cálida y funcional, permitiendo a los usuarios explorar recetas, leer consejos culinarios y disfrutar de un diseño limpio pensado para la lectura. Es una muestra de cómo combino estética, usabilidad y contenido para construir sitios web enfocados en la experiencia del usuario
